# brain

A "brain" built as a public GitHub repo. Memory is markdown, rules are files, the website is the face, and an HTTP API is how you call it. The code is Python standard library only.

- Site: https://fitzyracing1.github.io/brain/ (GitHub Pages from `docs/`, `pages.yml`)
- Static brain document: https://fitzyracing1.github.io/brain/api/v1/brain.json. OpenAPI spec: `docs/api/openapi.json`.
